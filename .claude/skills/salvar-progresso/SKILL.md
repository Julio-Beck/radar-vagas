# Salvar progresso

1. **Tickets em andamento:** atualize o status e escreva nas Notas o que está pronto, o que falta, as decisões tomadas (e o porquê) e a validação feita até agora. Não marque Done sem a validação do ticket concluída.
2. **Problemas descobertos:** acrescente ao Registro de problemas, com data e ticket relacionado. Nunca apague entradas.
3. **Dúvidas novas:** acrescente às Perguntas em aberto.
4. **Mudanças não commitadas:** mostre o git status e pergunte ao usuário se deve commitar no branch atual. Não commite por conta própria.
5. **Termine com uma frase** no formato: "Para continuar: <ticket>, <próximo passo concreto>."

Escreva de forma que uma sessão nova, sem nenhum histórico desta conversa, consiga continuar só lendo o docs/PLAN.md.
